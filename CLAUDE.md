# Projeto Darzan Produções (João Darzan)

Videomaker e storymaker em Campinas e região. Fale com o usuário **em português do Brasil**, de forma simples (leiga).

- **Logo oficial e identidade visual: veja `marca/README.md`.** Use sempre os arquivos de `marca/logo/`
  (versão principal: `marca/logo/darzan-logo-dourado.svg`). Não redesenhe a logo.
- Site: `darzan-producoes/` (conteúdo em `darzan-producoes/js/conteudo.js`). **No ar em https://darzanproducoes.netlify.app/** (endereço provisório, até comprar o domínio próprio). Publicado pelo Netlify a partir da branch `main` (`netlify.toml`); cada push na `main` atualiza o site sozinho.
- Financeiro: `financeiro/` (planilha + painel Google Apps Script; passo a passo em `financeiro/LEIA-ME.md`).
- **App de finanças:** `darzan-producoes/financas/`, dados no Supabase. Endereço principal (sem selo do Netlify): https://joaodarzan.github.io/meus-projetos/financas/ (GitHub Pages, `.github/workflows/publicar-github-pages.yml`, publica a cada push na `main`). O Netlify publica só o site: `darzanproducoes.netlify.app/financas` redireciona para o app no GitHub Pages (`netlify.toml`). Como funciona e como testar: `financas-app/README.md`. Rode os testes antes de publicar. Nunca coloque dados pessoais no repositório (é público).
