# Projeto Darzan Produções (João Darzan)

Videomaker e storymaker em Campinas e região. Fale com o usuário **em português do Brasil**, de forma simples (leiga).

- **Logo oficial e identidade visual: veja `marca/README.md`.** Use sempre os arquivos de `marca/logo/`
  (versão principal: `marca/logo/darzan-logo-dourado.svg`). Não redesenhe a logo.
- Site: `darzan-producoes/` (conteúdo em `darzan-producoes/js/conteudo.js`). **Endereço principal: https://darzanproducoes.joaodarzan10.workers.dev** (Cloudflare; provisório até comprar o domínio). O GitHub Pages (https://joaodarzan.github.io/meus-projetos/, `.github/workflows/publicar-github-pages.yml`) também publica e busca a lista de vídeos no robô da Cloudflare (`SITE.robo`). **Não redirecionar o GitHub para o workers.dev:** em algumas internets o `workers.dev` não abre (o João ficou sem acessar o site). Solução definitiva: domínio próprio. Cada push na `main` atualiza o site sozinho. O Netlify foi desligado (créditos do plano grátis acabavam a cada publicação). **Também na Cloudflare:** https://darzanproducoes.joaodarzan10.workers.dev (Workers, publica a `main`; `wrangler.jsonc` limita à pasta `darzan-producoes/` e liga o robô `cloudflare/worker.js`, que lista o bucket em `/api/videos`). **Vídeos são automáticos:** o que entra no bucket aparece sozinho no site (regras de nome em `carregarVideosDaNuvem`, `js/main.js`). Plano: vídeos no Cloudflare R2 (bucket `darzan-videos`, endereço público https://pub-130031e922ee48738efb8b8f3926986b.r2.dev) + domínio darzanproducoes.com.br.
- Financeiro: `financeiro/` (planilha + painel Google Apps Script; passo a passo em `financeiro/LEIA-ME.md`).
- **App de finanças:** `darzan-producoes/financas/`, dados no Supabase. Endereço: https://joaodarzan.github.io/meus-projetos/financas/ (GitHub Pages, publica a cada push na `main`). Como funciona e como testar: `financas-app/README.md`. Rode os testes antes de publicar. Nunca coloque dados pessoais no repositório (é público).
- **Salário CLT:** cai sempre no Inter (conta principal). Depois o João redistribui para outras contas dele e para cofrinhos/caixinhas: isso é **Transferência** ou **Guardado**, nunca renda nova nem gasto. Cada holerite: o João manda a foto na conversa; o Claude lança dividido em `LCLT-AAAA-MM-…` (mês em que caiu, banco Inter) e guarda inteiro na tabela `holerites` (todos os itens, totais e bases). Não há botão de foto no app (decisão do João: a leitura automática pelo app seria paga à parte).
- **Reembolso e Pix dividido:** dinheiro que alguém devolve (parte de uma compra no cartão, gasto adiantado num trabalho) não é renda: o Pix entra como grupo `Reembolso` e a parte do gasto que foi paga também vira `Reembolso` ("Reembolsado", não conta como gasto). Pix que mistura pagamento + reembolso: lançar as partes previstas como `LDV-<código>-<parte>` (mesmo banco); o robô confere o Pix inteiro com a soma das partes.
