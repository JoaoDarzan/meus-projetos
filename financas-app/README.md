# Darzan Finanças (app)

App pessoal de finanças do João Darzan: contas, cartões, trabalhos da Darzan Produções e da JPL SOM,
equipamentos, tarefas e metas. Funciona no celular (iPhone) e no computador.

## Situação
Em construção. O protótipo visual está pronto; agora o código está sendo organizado aqui e a base de dados
vai ser a planilha do Google "Planilha financeira 2.0" (privada, no Drive do João).

## Pastas
| Pasta | O que tem |
|---|---|
| `js/util.js` | dinheiro, datas, ícones |
| `js/calculos.js` | contas do mês, faturas, saldos, tarefas e dicas (só lê os dados) |
| `js/dados.js` | guarda e altera os dados (hoje no aparelho; depois na planilha) |
| `js/icones.js` | ícones Lucide (licença ISC) |
| `ferramentas/` | scripts de apoio (extrair ícones, importar dados) |
| `dados/` | **dados pessoais: não vão para o GitHub** (ver `.gitignore`) |

## Privacidade
Este repositório é público. Valores, extratos, nomes de clientes e fotos ficam só na planilha do Google
e no aparelho do João, nunca aqui.
