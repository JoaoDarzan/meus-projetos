# Marca: Darzan Produções

Logo original e versões vetorizadas (recriadas a partir da original, com as mesmas medidas).

| Arquivo | Uso |
|---|---|
| `logo-original.png` / `.webp` | A logo enviada (com fundo e efeito de relevo) |
| `logo.svg` | Vetor dourado, fundo transparente. Use em site, impressos e vídeo |
| `logo-fundo.svg` | Vetor dourado sobre o fundo grafite |
| `logo-branca.svg` | Uma cor (branca), para marca d'água |
| `logo-emblema.svg` | Só o emblema (rolo de filme + obturador + seta), para ícone e avatar |
| `logo-partes.svg` | Uma camada por parte (`rolo`, `obturador`, `play`, `seta`, `anel-externo`, `anel-interno`, `louro`, `texto-darzan`, `texto-producoes`). É a base da logo 3D do vídeo |
| `logo-4096.png` | PNG transparente em alta (4096 px) |
| `logo-fundo-2048.png` | PNG com fundo grafite (2048 px) |
| `logo-branca-2048.png` | PNG branco transparente (2048 px) |

Fontes usadas na recriação: **Cinzel** (DARZAN) e **Montserrat** (PRODUÇÕES), ambas livres (Google Fonts).
Os textos estão convertidos em contornos, então o SVG abre igual em qualquer programa.

Cores: ouro `#E2B850`, ouro claro `#F7E08A`, ouro escuro `#A87A28`, grafite `#1E2023`.

Para gerar os SVGs de novo: `python3 construir_logo.py` (precisa de `shapely` e `fonttools`).
