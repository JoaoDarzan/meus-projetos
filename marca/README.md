# Identidade visual — Darzan Produções

**Logo oficial** (enviada por João Darzan em 21/10/2026): selo circular dourado com rolo de filme,
diafragma de câmera com botão de play, seta de crescimento, ramo de louro, **DARZAN** em serifa clássica
e **PRODUÇÕES** em fonte geométrica (Montserrat) bem espaçada.

Sempre use os arquivos da pasta `logo/`. Não redesenhe a logo.

## Arquivos da logo (`logo/`)

| Arquivo | Quando usar |
|---|---|
| `darzan-logo-dourado.svg` / `.png` / `.pdf` | **Versão principal.** Vetor dourado com degradê, sem fundo. SVG/PDF para gráfica, adesivo, camiseta, placa; PNG para redes e vídeos |
| `darzan-logo-ouro-solido.svg` / `.png` | Dourado de uma cor só (bordado, carimbo, gravação a laser, serigrafia) |
| `darzan-logo-branco.svg` / `.png` | Sobre fotos e vídeos, fundos escuros (marca d'água de vídeo) |
| `darzan-logo-preto.svg` / `.png` | Fundos claros, documentos, contratos, impressão em preto |
| `darzan-logo-realista-sem-fundo.png` | Efeito dourado 3D da arte original, sem fundo (redes sociais, vinhetas) |
| `darzan-logo-original-fundo-escuro.png` | Arte original com fundo escuro, sem a marca d'água |
| `darzan-logo-arquivo-original.webp` | Arquivo original recebido (guardar, não usar) |
